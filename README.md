# OCO Canvas Car Scene Compare

A static gallery comparing single-file HTML canvas animations produced from the same prompt by separate OpenCodeOrchestra Orchestrator runs.

- Inspired by: https://www.reddit.com/r/LocalLLaMA/comments/1tf3p6c/local_qwen_36_vs_frontier_models_on_a_coding/
- Harness: https://github.com/AidenGeunGeun/OpenCodeOrchestra
- Setup: same prompt, one Orchestrator per model, highest available thinking/effort settings.

Open `index.html` to view the gallery.
